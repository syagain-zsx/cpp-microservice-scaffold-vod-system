# 能力检查点（CP1 / CP2 / CP3）

> 检查点不是“考试”，而是**证明你学会了**的三件套：**跑（命令）+ 改（diff）+ 讲（录音/白板）**。
> 缺一件都算没通过；宁可少做任务，也要把三件套做完整。

## CP1（第 2 周末）· 请求穿过网关 + 服务发现

| 项 | 要求 | 通过线 |
| --- | --- | --- |
| 跑 | `run-dev.sh start/status/stop`、curl 登录/列表/下载、etcd 查询 | 全部成功，无手工救场 |
| 改 | lease TTL 10s→5s（或给 tempLogin 加耗时日志） | diff 可编译、可运行、能说出影响 |
| 讲 | 5 分钟白板：client → gateway → etcd → user → MySQL | 覆盖注册、发现、失效三点 |

**讲稿骨架**：

```text
1. 服务启动时做了什么（建连接、注册、KeepAlive）
2. 网关怎么发现它（watch + list + 5s resync）
3. 请求怎么过去（Channel、超时、错误码）
4. 服务挂了会怎样（lease 过期、节点移除、请求失败）
5. 为什么 watch 要先于 list
```

**自检题**：如果 etcd 整个挂了，已启动的服务还能互相调用吗？新服务还能上线吗？

## CP2（第 4 周末）· 异步链路排障

| 项 | 要求 | 通过线 |
| --- | --- | --- |
| 跑 | 触发一次上传/投递，`tail transcode.log`，curl 到 m3u8 | 链路可复现，能指出日志行 |
| 改 | 给“源文件不存在”加失败分支 + 验证 | 失败有明确日志、状态不变、正常链路仍 18/18 |
| 讲 | 10 分钟：上传 → 转码 → HLS → 审核 + 4 个队列 + 状态机 | 能解释消息丢失/重复消费场景 |

**讲稿骨架**：

```text
1. 为什么异步：上传只落盘 + 写库，转码不阻塞用户
2. 四类队列分别做什么（含两个延迟队列）
3. 转码做了什么（remux、hls_time、ts/m3u8、更新 video_fid）
4. 状态机：5 → 1 → 2 / 3 / 4
5. 失败与幂等：转码失败停 5；重复消费会怎样
```

**自检题**：MQ 里消息丢了会怎样？如何发现？怎么补？

## CP3（第 6 周末）· 交付与答辩

| 项 | 要求 | 通过线 |
| --- | --- | --- |
| 跑 | 全新 build + ctest 8/8 + smoke 4/4 + e2e 18/18 + check-api 38/38 + bench | 全绿，输出可贴 |
| 改 | 一个已合并的改进（diff + 测试/验证） | 可演示、可回滚 |
| 讲 | 15 分钟模拟面试 10 题（架构/缓存/MQ/排障/优化） | 至少 8 题答到点 |

**自检题**：

1. 这个项目如果 DAU 涨 100 倍，先崩哪里？怎么改？
2. 哪一处设计你现在会重做？为什么？
3. 你亲手改过什么？遇到过什么 bug？怎么定位的？

## 评分表（每项 0–2 分，满分 12）

| 维度 | 0 | 1 | 2 |
| --- | --- | --- | --- |
| 命令是否独立完成 | 需要提示 | 少量提示 | 独立完成 |
| diff 是否可运行 | 编译失败 | 能跑但解释不清 | 可运行 + 解释动机 |
| 讲解是否脱稿 | 照读 | 偶尔看稿 | 脱稿 + 能画图 |
| 能否接住追问 | 答不上 | 部分 | 有取舍、有数据 |
| 是否留下证据 | 无 | 部分 | 图 + diff + 录音齐全 |
| 面试题覆盖 | <5 题 | 5–7 题 | ≥8 题 |

**通过线**：≥ 9 分，且“命令独立完成”与“讲解脱稿”不得为 0。
